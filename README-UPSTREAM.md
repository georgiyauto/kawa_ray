Лицензия: GPL-3.0-only, текст `LICENSE`, оригинальное авторство и дополнительное разрешение для Wintun — `LICENSE-EXCEPTION.md`.
Лицензия vendored DUOTUN: MIT, полный оригинальный текст в `vendor/DUOTUN/LICENSE`.
Сторонние компоненты и необходимые уведомления перечислены в `THIRD-PARTY-NOTICES.md` и `THIRD-PARTY-CRATES.txt`.

Рабочая документация модифицированного приложения находится в `README.md`.
