# Kawa VPN

VPN-клиент на [Xray-core](https://github.com/XTLS/Xray-core) с подписками Xray JSON, маршрутизацией и кабинетом. Desktop-интерфейс написан на Slint, логика — на Rust. Android-версия — отдельный нативный клиент на Kotlin с системным VpnService.

Kawa VPN — модифицированная версия [KAWARAY](https://github.com/m-a-prod/DUORAY). Изменения Kawa: собственный интерфейс, кабинет, работа с подписками и заказами, обновления, диагностика, глобус и анимации, защита помощника. Дата подготовки этой модификации: **22 октября 2026**. Происхождение базы: `SOURCE-ORIGIN.json`.

## Версия 0.4.40

- Android: подключение мгновенное, как в Happ и Incy — «Защищено» сразу после запуска Xray, проверка связи идёт в фоне, а неответивший туннель переподключается автоматически.

- Android и Windows: флаг и название сервера берутся из конфига (🇳🇱 → Нидерланды), а не из GeoIP адреса выхода; «Авто-регион» так и называется, а не страной, куда подключился.

## Версия 0.4.39

- Android: пока VPN подключается, запросы подписки и кабинета идут через обычную сеть телефона, а не в ещё не поднятый туннель (больше нет ложной ошибки «DNS не смог найти сервер»).

## Возможности

- Подписки с полным Xray JSON: сохраняются DNS, маршрутизация и балансировщики панели. Доступен ручной импорт VLESS, VMess, Trojan и Shadowsocks.
- Подключение через системный TUN-помощник, выбор сервера, поиск, фильтры и избранное.
- Пинг выбранного подключения, время сессии и скорость, интерактивный глобус с маршрутом.
- Маршрутизация сайтов, адресов, локальной сети и приложений в пределах возможностей платформы.
- Кабинет, баланс, подписки и восстановление состояния заказа после перезапуска. Факт оплаты отдельно проверяется сервером и не подменяет выдачу услуги.
- Обновления Kawa с проверкой Ed25519-подписи манифеста, размера и SHA-256 установщика.
- Отправка диагностики по правилам согласия, указанным в приложении. Пользовательские ключи, пароли и подписки не входят в архив исходников.

Лимит трафика Kawa относится к серверам обхода; условия обычных серверов отображаются в кабинете.

## Как устроено

```text
Kawa VPN desktop (Rust / Slint)
  ├─ кабинет, подписки, серверы, настройки
  ├─ Xray: локальный SOCKS с отдельными случайными учётными данными
  └─ локальное IPC → KawaVPNHelper → KAWATUN → системный TUN

Kawa VPN Android (Kotlin / Compose)
  └─ системный VpnService → встроенный Xray и пакетный туннель

Кабинет Kawa
  └─ вход через бота, подписки и обработка заказов
```

| Каталог | Назначение |
|---|---|
| `crates/kawaray-core` | Подписки, ссылки, конфигурации Xray, кабинет и протокол помощника |
| `crates/kawaray-gui` | Desktop-приложение, бинарник `KawaVPN` |
| `crates/kawaray-helper` | Системный помощник, бинарник `KawaVPNHelper` |
| `vendor/KAWATUN` | Исходный код TUN-движка с MIT-лицензией |
| `packaging` | Сборка установочных пакетов и проверка подписи |
| `server/kawaray-hub` | Сервис обновлений и диагностики; для своей установки нужна отдельная конфигурация |
| `tools` | Генераторы ресурсов, проверка и создание архива исходников |

## Сборка desktop

Нужен Rust stable. KAWATUN уже включён в `vendor/KAWATUN`; соседние репозитории и закрытые deploy keys не требуются.

```sh
cargo test --locked --workspace
cargo build --locked --release -p kawaray-gui -p kawaray-helper
```

Windows: Rust MSVC с Visual Studio Build Tools либо GNU с MinGW-w64 и windres. Linux: системные библиотеки окон, шрифтов и ввода согласно упаковке/CI. macOS: Xcode Command Line Tools и нужный Rust target.

Для рабочего подключения рядом с приложением нужны соответствующий платформе Xray и geo-базы. Windows дополнительно использует Wintun. Версии, хеши и упаковка фиксируются в скриптах `packaging/`; не заменяйте их непроверенными бинарниками.

Упаковка: [packaging/README.md](packaging/README.md). Android, подготовка зависимостей и подпись APK: [android/README.md](android/README.md). Для нового сервиса кабинет, бот, DNS и release endpoints настраиваются отдельно: репозиторий не содержит production-секретов Kawa и не разворачивает чужую инфраструктуру автоматически.

## Исходный архив

```sh
python tools/test_source_distribution.py
python tools/make-source-archive.py --version 0.4.27 --output dist/KawaVPN-0.4.27-source.zip
```

В архив входят исходники, vendored KAWATUN, ресурсы, лицензии, lock-файлы и инструкции. `SOURCE-MANIFEST.json` фиксирует SHA-256 каждого файла. Сборочные каталоги, учётные записи, `.env` и приватные ключи исключены.

## Проверки

Windows 0.4.25: 64 теста интерфейса, 44 ядра, 13 кабинета и 8 помощника; 14 снимков интерфейса; проверенное полное скачивание через подписанный канал обновления. Эти результаты относятся к выпущенной 0.4.25 и не объявляются проверкой будущих Linux/macOS/Android-сборок.

Тесты кабинета используют заглушки для платёжных операций. Реальные платежи не выполняются автоматически. Подключение, разрешения ОС, восстановление сети и работа на устройстве проверяются отдельно для каждой целевой платформы.

## О публичной версии

В этом репозитории адреса сервисов Kawa (кабинет, сервер отчётов и обновлений, бот) заменены на заглушки `example.com` и `your_bot`. Чтобы собрать рабочий клиент для своего сервиса, укажите свои адреса в `crates/kawaray-core/src/cabinet.rs`, `crates/kawaray-gui/src/diag.rs`, `android/app/src/main/kotlin/pro/vinnikov/kawavpn/data/KawaRepository.kt`, `.../account/BillingClient.kt`, `.../diag/Diagnostics.kt` и `android/domain/.../NetworkContract.kt`. Полный исходный код каждой выпущенной сборки также вложен в саму сборку.
