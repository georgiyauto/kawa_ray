Kawa VPN — desktop

Установите Kawa VPN и нажмите «Мой Kawa VPN» → «Войти через Telegram».
Добавьте ссылку на подписку: серверы загрузятся автоматически.

Покупка и продление:
1. В «Мой Kawa VPN» выберите подписку для продления или тариф для покупки.
2. Выберите период и способ Platega, нажмите кнопку покупки.
3. Оплатите открывшийся счёт. Приложение проверяет оплату и выдачу каждые 15 секунд.
4. Счёт и состояние заказа сохраняются; после перезапуска проверка продолжится.
Если денег на балансе достаточно, отдельный счёт не создаётся.
Минимум пополнения Platega может превышать недостающую сумму; остаток остаётся на балансе.
Лимит тарифа относится только к обходам. Обычный VPN безлимитный.
После смены аккаунта подписки предыдущего аккаунта удаляются из приложения.
Поддержка: через сервис, выдавший подписку.

Для подключения через TUN установщик регистрирует службу KawaVpnHelper.
Ручной импорт ссылок и настройки маршрутизации также доступны.
Обновления проверяются и скачиваются автоматически с Германии.
Когда обновление готово, нажмите «Установить» в полосе обновления.
Настройки → Сообщить о проблеме: отчёт с очищенными логами, ОС, моделью, CPU/RAM и публичным IP провайдера получает поддержка через главного бота.
IP провайдера определяется отдельным HTTPS-запросом к Kawa через физическую сеть, вне VPN, только при разрешённой отправке отчёта. Если определить IP не удалось, локальный адрес вместо него не показывается.
Автоматические отчёты требуют подробного согласия с подтверждением прочтения.
В активной базе хранение до 90 дней; сообщения Telegram автоматически по этому сроку не удаляются.
Удаление полученных отчётов: обратитесь в поддержку сервиса с кодом KW-.
Настройки → ПИНГ → «Проверять пинг при запуске»: по умолчанию выключено. При включении список проверяется один раз после запуска; дальше проверка только по кнопке. Сортировка «Пинг ↑» использует уже полученные результаты и сохраняется между запусками.
Цифра пинга — TCP-соединение через физическую сеть. Доступность VPN проверяется отдельно через HTTP. OK означает доступный VPN без успешного TCP-замера.
PrintScreen и Ctrl+Shift+S сохраняют снимок приложения и копируют его в буфер обмена. Клавиша PrintScreen наблюдается только для активного окна; системное действие клавиши не блокируется.
Красный флажок в главном меню открывает отправку репорта. Лицензии открываются внутри приложения.
Версии 0.4.7 и 0.4.8 обновите вручную этим установщиком. С 0.4.9 работает встроенное обновление.

Системный трей Windows:
Значок Kawa VPN → правая кнопка мыши: подключить выбранный сервер, отключить, закрыть приложение с отключением VPN. Щелчок по значку возвращает окно.
