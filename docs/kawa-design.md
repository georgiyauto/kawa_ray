# Kawa VPN: адаптация KAWARAY

Дата: 6 октября 2026. Статус: реализован Windows x64 клиент Kawa VPN 0.4.0 с оплатой Platega. Результаты и границы проверки — в VALIDATION.md.

## Результат

Клиент Kawa VPN на основе KAWARAY: вход через @your_bot, автоматическая загрузка своего аккаунта и серверов, покупка и продление существующих тарифов Kawa. Существующие пользователи, баланс, платежи и подписки сохраняются в действующей базе сервиса.

Предлагаемый первый выпуск — Windows x64 с установщиком. KAWARAY является настольным клиентом; Android не входит в эту версию. Выбор платформы и способа оплаты вынесен пользователю отдельными вопросами.

## Найдено в исходниках

- KAWARAY: Rust, Slint, Xray и привилегированный помощник Kawatun. Репозиторий скопирован в `work/kawa-vpn-app`.
- Поддерживаются полные JSON-конфигурации, DNS и балансировщики панели. Их нужно сохранить, включая авто-регион и авто-обход Kawa.
- Привязка к upstream: кнопка покупки, проверка доменов подписки, каталог данных, оформление, адреса диагностического сервера и канал подписанных обновлений.
- Кабинет Kawa: `https://example.com`, API `/api/cabinet`.
- Уже существуют запрос и опрос авторизации `/auth/deeplink/request` и `/auth/deeplink/poll`, подтверждение в боте, обновление и отзыв сессий.
- API кабинета выдаёт данные аккаунта, подписку и варианты покупки. Приложение должно переиспользовать эту бизнес-логику.

## Вход и автоматическая загрузка

1. На первом экране пользователь нажимает «Войти через Telegram».
2. Клиент создаёт одноразовый запрос входа в API и открывает ссылку на бота.
3. Пользователь подтверждает вход кнопкой в боте. Сам переход по ссылке не считается подтверждением.
4. Клиент опрашивает результат с учётом срока действия, отмены и ограничения запросов; получает сессию только после подтверждения.
5. Загружаются имя, баланс, тариф, срок, лимит обходов, устройства и собственная ссылка подписки. Серверы импортируются автоматически без ручного копирования ссылки.
6. При повторном запуске сессия обновляется; при её отзыве показывается повторный вход. Выход отзывает сессию и удаляет локальные секреты.

Для Windows токены хранятся под защитой DPAPI, отдельно от обычного JSON настроек. JWT, коды входа и ссылки подписки не выводятся в журналы. В клиенте нет ключей Remnawave и токена Telegram-бота.

## Подписка, покупка и продление

В аккаунте отображаются баланс, срок и тариф. Лимит подписывается «Трафик обходов»; обычный VPN обозначается как безлимитный. Цены, устройства и доступные периоды загружаются из кабинета, не зашиваются в приложение.

Рекомендуемый сценарий: использовать текущую оплату Kawa. Если выбран вариант с существующим кабинетом, кнопка покупки или продления открывает кабинет и его штатную оплату, а клиент обновляет данные после возвращения. Не передавать долгоживущие токены в URL: для бесшовного перехода нужен короткоживущий одноразовый обмен сессией на сервере.

Если пользователь выбирает отдельные экраны внутри клиента, тариф, период и способ оплаты выбираются там через существующие API. Страница внешнего платёжного сервиса открывается в браузере. Продление подтверждается серверным webhook; возвращение пользователя со страницы оплаты само по себе не подтверждает платёж. Повторное нажатие не должно создавать двойное списание.

Оплаченная подписка автоматически обновляется в приложении. Истёкшая подписка сохраняет доступ к аккаунту и покупке, но не изображает рабочее VPN-подключение.

## Брендинг и независимость

- Название и оформление Kawa VPN; ссылки покупки и поддержки ведут в сервис Kawa.
- Отдельные каталог настроек, идентификаторы приложения и установщик, не конфликтующие с KAWARAY.
- Удалить обращения к диагностическим и обновляющим серверам upstream. Не принимать обновления, подписанные исходным ключом KAWARAY.
- Для самостоятельного автообновления потребуется канал сборок Kawa с отдельным ключом подписи. Пока он не настроен, не выдавать чужие обновления за обновления Kawa.
- Сохранить GPL-3.0, исходные сведения об авторстве и сторонних компонентах. Пользовательский брендинг меняется; юридические notices остаются.

## Проверки перед выпуском

- Вход: ожидание, отказ, истечение кода, повторное использование, успешное подтверждение, отзыв и обновление сессии.
- Импорт: только собственная подписка, отсутствие подписки, истечение срока, потеря сети, отсутствие дубликатов после обновления.
- VPN: сохранность маршрутов, DNS и балансировщиков; подключение через Германию, Нидерланды и LTE; корректное восстановление сети после отключения.
- Оплата: действующие цены и периоды, успешный webhook, отмена, задержка, отсутствие повторного списания.
- Сборка установщика Windows, установка, запуск, отключение, удаление; проверка отсутствия обращений к серверам upstream.

Сборка выполняется локально, Rust/Cargo и MinGW установлены в каталоге рабочего пространства. KAWATUN лежит рядом с приложением.
